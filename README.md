# Mading Digital XII IPA 1

*Last updated: 2026-08-07*

Mading digital interaktif untuk kelas XII IPA 1 — tema papan gabus (corkboard) dengan sticky note, kertas tempel, dan font handwriting.

---

## File Project

| File | Fungsi |
|------|--------|
| `index.html` | Halaman utama (1227 baris) — semua seksi kelas |
| `auth.js` | Autentikasi Supabase (login/daftar) + gate komentar |
| `auth.css` | Styling modal login/daftar |
| `README.md` | Laporan project ini |

## Seksi di Halaman

1. **Hero** — papan gabus + id-tag kelas (TA 2025/2026)
2. **Struktur Kelas** — pengurus + seksi (sticky note)
3. **Wali Kelas** — kartu laminating + lanyard
4. **Profil Siswa** — carousel kartu pelajar (geser + ketuk untuk detail)
5. **Jadwal Pelajaran** — papan jadwal tempel + chip mapel berwarna
6. **Piket** — kartu checklist per hari
7. **Denah** — papan tulis hijau + grid tempat duduk
8. **Dokumentasi** — polaroid kegiatan
9. **Prestasi** — medali kelas
10. **Komentar** — sticky note (wajib login via Supabase)
11. **Kontak & Footer**

## Teknologi

- HTML + CSS murni (token design, responsive, micro-interaction)
- Google Fonts: `Archivo Black`, `Caveat`, `Patrick Hand`, `Work Sans`
- Supabase (auth + DB) — URL/key sudah terisi di `auth.js`
- Komentar disimpan **permanen** ke tabel `comments` (Supabase), tampil untuk semua pengunjung

### 2026-08-07 — Komentar Permanen (Supabase DB)
- Komentar tidak lagi di memori sesi; disimpan ke tabel `comments` di Supabase.
- Semua pengunjung bisa melihat komentar (tanpa login cukup baca).
- Hanya pengguna yang login yang bisa menambahkan komentar.
- `auth.js` mengekspos `window.supabaseClient` agar dipakai halaman utama.
- **WAJIB**: buat tabel di dashboard Supabase → SQL Editor, jalankan SQL di bawah ini.

```sql
create table public.comments (
  id bigint generated by default as identity primary key,
  name text not null,
  message text not null,
  created_at timestamptz not null default now()
);

alter table public.comments enable row level security;

create policy "Baca komentar bebas" on public.comments
  for select using (true);

create policy "Login boleh tambah komentar" on public.comments
  for insert with check (auth.uid() is not null);
```

### 2026-08-07 — Akun Admin (bisa hapus komentar orang lain)
- Tabel `profiles` baru (id → auth.users, `is_admin` boolean). Auto dibuat saat user daftar (trigger `on_auth_user_created`).
- Fungsi `public.is_admin()` untuk mengecek status admin dari JWT.
- Policy delete pada `comments`: hanya `is_admin()` yang boleh hapus (RLS).
- UI: tombol ✕ muncul di tiap sticky-note hanya untuk admin; klik → konfirmasi → hapus permanen.
- Navbar admin menampilkan `🛡️ Admin (...)`.
- **Cara jadikan admin** (SQL Editor):
  ```sql
  update public.profiles set is_admin = true
  where id = (select id from auth.users where email = 'EMAIL_ADMIN');
  ```

### 2026-08-07 — Search Bar + Statistik Pencarian (Supabase)
- Tombol pencarian (ikon kaca pembesar SVG) di navbar, buka panel kertas; shortcut `Ctrl+K`.
- Mencari: **Seksi** (10), **Siswa** (dari DOM otomatis), **Pengurus** (dari DOM), **Mapel** (12), **Hari** (5).
- Peringkat hasil: startsWith > contains; highlight kata yang cocok (`<mark>`).
- Keyboard: ↑ ↓ pilih, Enter buka, Esc tutup; tombol ✕ atau klik luar menutup.
- Klik hasil → scroll halus ke seksi terkait.
- **Log pencarian** ke tabel `searches` (query + jumlah hasil). RLS: insert bebas (siapa pun), select **hanya admin**.
- Seksi **"Top Pencarian"** baru (id `#analytics`) — muncul hanya saat admin login, menampilkan 10 kata paling sering dicari + bar proporsi.
- **Tabel `searches`:**
  ```sql
  create table public.searches (
    id bigint generated by default as identity primary key,
    query text not null,
    results bigint not null default 0,
    created_at timestamptz not null default now()
  );
  alter table public.searches enable row level security;
  create policy "Simpan pencarian bebas" on public.searches
    for insert with check (true);
  create policy "Hanya admin baca statistik" on public.searches
    for select using (public.is_admin());
  ```

### 2026-08-07 — Fix Tampilan Android Ngaco (zoom bocor ke mobile)
